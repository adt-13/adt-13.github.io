# Backend - FastAPI Portfolio API

## Run locally

```bash
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Open API docs:

```txt
http://localhost:8000/docs
```

Main endpoint:

```txt
http://localhost:8000/api/portfolio
```
